# KIŠIB.Hasty-JSON Importer
A specified import app that converts Hasty exports into the data file format we need to import it into our database. The idea behind this app is found in [matanat](https://github.com/matanat)'s [acawai script](https://github.com/matanat/acawai). This app is based on JavaScript however and can be run on any server essentially.
